# Котлован — приложение для просмотра инженерных чертежей

## Описание
Приложение для Android, позволяющее удобно просматривать одинаковые помещения
на схемах разных инженерных коммуникаций. Создаёт массивы ячеек с изображениями
чертежей, поддерживает систему общих точек, комментариев и синхронизированный
просмотр с общим зумом и позиций.

## Сборка APK

### Вариант 1: На Linux / WSL (рекомендуется)

```bash
# Установите зависимости системы
sudo apt update
sudo apt install -y python3-pip python3-setuptools git zip unzip openjdk-17-jdk

# Установите Buildozer
pip3 install buildozer

# Установите Cython (нужен для сборки)
pip3 install "cython<3"

# Перейдите в папку проекта
cd /путь/к/проекту

# Соберите APK (первая сборка может занять 30-60 минут)
buildozer -v android debug
```

Готовый APK будет в папке `bin/`.

### Вариант 2: Через Docker

```bash
docker run --rm -v $(pwd):/home/user/hostcwd kivy/buildozer android debug
```

### Вариант 3: Через GitHub Actions

Создайте файл `.github/workflows/build.yml`:

```yaml
name: Build APK
on: push
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Build with Buildozer
        uses: ArtemSBulgakov/buildozer-action@v1
      - name: Upload APK
        uses: actions/upload-artifact@v3
        with:
          name: kotlovan.apk
          path: bin/*.apk
```

## Установка на телефон

```bash
# Скопируйте APK на телефон
adb install bin/kotlovan-1.0-debug.apk
```

Или просто перенесите файл APK на телефон и откройте его.

## Структура сохраняемого массива

При сохранении создаётся папка:
```
Имя_массива/
├── config.json          # конфигурация массива
├── image_0_0.png        # изображения ячеек
├── image_0_1.jpg
└── ...
```

### Формат config.json

```json
{
  "rows": 3,
  "cols": 3,
  "array_name": "Имя массива",
  "shared_zoom": 1.0,
  "shared_offset_x": 0.0,
  "shared_offset_y": 0.0,
  "current_row": 0,
  "current_col": 0,
  "cells": {
    "0,0": {
      "title": "Название ячейки",
      "image_path": "image_0_0.png",
      "image_filename": "image_0_0.png",
      "own_position": false,
      "common_point": [500.0, 400.0],
      "comments": [
        {
          "x": 250.0,
          "y": 200.0,
          "size": 20,
          "title": "Замечание",
          "text": "Текст комментария"
        }
      ],
      "own_zoom": 1.0,
      "own_offset_x": 0.0,
      "own_offset_y": 0.0
    }
  }
}
```

## Управление в режиме просмотра

- **Свайп влево/вправо** — следующая/предыдущая ячейка в строке
- **Свайп вверх/вниз** — следующая/предыдущая ячейка в столбце
- **Щипок (два пальца)** — масштаб относительно центра между пальцами
- **Перетаскивание двумя пальцами** — панорамирование
- **Двойное касание фонарика** — включить/выключить фонарик
- **Двойное касание иконки глаза** — переключение режима отображения комментариев
- **Двойное касание кружка комментария** — прочитать текст
- **Долгое нажатие на кружок комментария** — редактирование

## Функции

- Создание массива ячеек с изображениями чертежей
- Система "Общая точка" для синхронизации вида между разными чертежами
- Режим "Свое положение" для независимого просмотра отдельной ячейки
- Комментарии-кружки на изображениях с текстом
- Три режима отображения кружков комментариев (глаз)
- Настройка размеров и прозрачности иконок
- Сохранение/загрузка массивов в папку с config.json
- Фонарик телефона
